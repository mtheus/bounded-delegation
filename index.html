Abstract

AI coding agents have made individual developers dramatically faster at writing code, yet team-level delivery outcomes are deteriorating: review queues are growing, pull requests are getting larger and less reviewed, and bug rates are rising. This paper argues that code generation is no longer the bottleneck in software engineering — verification is. Drawing on controlled experiments, large-scale telemetry, and a landmark trial with experienced open-source maintainers, it shows that developers consistently overestimate the productivity gains of AI assistance while measurable delivery outcomes decline. A three-layer model of software debt — Technical, Cognitive, and Intent debt — explains why superficially clean, agent-generated code can still erode a team's ability to safely evolve a system.

The Bounded Delegation Hypothesis (H₀): delegating implementation to coding agents is sustainable if, and only if, delegation is bounded on one side by human-owned Intent (problem statement, domain language, architectural decisions) and on the other side by human-readable Evidence (executable scenarios and test results).

Five takeaways

01

Verification, not generation, is the new bottleneck

PR volume and size are up, review time is up 441%, and 31% of PRs merge with no human review at all.

02

Technical debt falls; cognitive & intent debt explode

Agents reduce boilerplate but erode shared mental models and unrecorded rationale faster than ever.

03

Stop reading implementation — adopt Bounded Delegation

Bound delegation with human-owned Intent and human-owned Evidence; let agents own the path between.

04

Traditional Agile rituals lose their rationale

Sprints and velocity rationed scarce typing hours. The new constraint is human decision bandwidth.

05

Code health matters more for machines than for humans

Deep modules and co-located README contracts keep agent context windows small and reasoning safe.

The seven knowledge layers

1Intent · HumanProblem — statement, target user, constraints, success criteria
2Intent · HumanDomain — ubiquitous business language, term by term
3Intent · HumanDecisions / ADRs — machine-checkable architectural assertions
4DelegatedStructure — C4 architecture model + co-located component contracts
5DelegatedPatterns — recurring implementation designs and workflow steps
6DelegatedSteps — active increments with delta specs over the layers above
7Evidence · HumanInspectable executable scenarios + automated evaluation suites
